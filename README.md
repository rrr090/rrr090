## Featured: [dronelab](https://github.com/rrr090/dronelab)

Reinforcement learning for drone teams carrying slung cargo through wind, gusts and generated obstacle maps. It has NumPy physics, PPO written from scratch in PyTorch, and three.js 3D viewers.
